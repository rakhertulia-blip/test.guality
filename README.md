Т118 — Автотесты

Описание проекта

Проект предназначен для проверки функций Python с помощью автоматических тестов "assert".

Файлы проекта

- "quality.py" — функции для проверки баллов, статусов, изменения записей и подсчёта результатов.
- "test_quality.py" — автоматические тесты для проверки работы функций.
- "README.md" — описание проекта и инструкция по запуску.
- "checks.md" — результаты проверок и найденные ошибки.

Как запустить

1. Открыть папку проекта.
2. Запустить файл "test_quality.py".
3. Проверить результаты в консоли.

Также можно запустить командой:

python test_quality.py

Результат

При успешном прохождении всех четырёх основных тестов выводится сообщение "Итого: 4/4 теста пройдены".
